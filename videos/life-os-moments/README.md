# Life OS: moments and ceremonies (HyperFrames preview)

The approved timing for Phase 10 of Life OS (`life-os/docs/product-architecture.md`, section 10.4),
rendered locally as a portrait preview before the in-app versions were built. Not shipped with the app.

Seven scenes, 37 s at 1080 × 1920: a new level (0–5 s), a personal record (5–8.5 s), the last of your
three (8.5–12 s), seal the day (12–17 s), the season finale (17–23 s), the monthly film (23–32 s) and
your year (32–37 s). Black, white and one blue, Inter, no confetti.

```sh
npm run check    # lint, layout and contrast
npm run render   # draft render to renders/life-os-moments.mp4 (local, no credits)
```
