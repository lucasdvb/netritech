# Life OS: the comeback moment (HyperFrames preview)

The timing for Phase 13's comeback moment (`life-os/docs/product-architecture.md`, Phase 13, item 4), rendered
locally as a portrait preview before it was built into the app, like every moment. Not shipped with the app.

Two scenes, 7 s at 1080 × 1920: light (0–3.5 s) and dark (3.5–7 s). The first time a habit counts after a miss,
its row ticks, a fine blue line draws around it and a plate engraves: "Back to Reading · Coming back is the habit."
Once a day for each habit. Black, white and one blue, Inter, no confetti.

```sh
npm run check    # lint, layout and contrast
npm run render   # draft render to renders/life-os-comeback.mp4 (local, no credits)
```
